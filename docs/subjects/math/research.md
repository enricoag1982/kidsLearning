## 1. Principles

| # | Principle | Evidence | App rule |
|---|---|---|---|
| 1 | Concrete → pictorial → abstract | [EEF](https://eric.ed.gov/?id=ED634883) rec. 2; [IES](https://files.eric.ed.gov/fulltext/ED532215.pdf): draw before notation; [NCETM](https://www.ncetm.org.uk/teaching-for-mastery/mastery-explained/five-big-ideas-in-teaching-for-mastery/): representations expose structure | Story/Demo = draggable objects; guided tries = bars, arrays, lines; scored items tagged C/P/A; last 2 of 8 A-only; narrate the link between them |
| 2 | Number sense before procedures | Number-line estimation vs achievement r≈.44 ([meta](https://www.researchgate.net/publication/323178327_Associations_of_Number_Line_Estimation_With_Mathematical_Competence_A_Meta-analysis)); [linear board game](https://siegler.tc.columbia.edu/wp-content/uploads/2019/02/sieg-ram09.pdf) gains held 9 wks; [IES fractions guide](https://ies.ed.gov/ncee/wwc/practiceguide/15): number line central | Number line in every world; estimate before compute; "sensible?" check; compare/order before algorithms |
| 3 | Fluency = short spaced retrieval | Spacing d≈0.54 in classrooms ([2025 meta](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC12189222/)); [flashcards beat chanting](https://hechingerreport.org/proof-points-flashcards-prevail-over-repetition-in-memorizing-multiplication-tables/) (NL RCT); [McNeil 2025](https://www.psychologicalscience.org/news/2025-april-pspi-math.html): timed practice only after accuracy | Leitner per fact and per concept; 3–5 review items/session, typed not recognised |
| 4 | Worked examples, then fading | [Fading effect](https://www.researchgate.net/publication/2398854_From_Studying_Examples_to_Solving_Problems_Fading_Worked-Out_Solution_Steps_Helps_Learning); IES: students explain steps | Demo = full narrated example; try 1 last step open, try 2 two steps open, try 3 full with hints; "which reason is right?" items |
| 5 | Variation + interleaving | NCETM variation; [Rohrer RCT](https://gwern.net/doc/psychology/spaced-repetition/2019-rohrer.pdf) (54 classes) | Contrast pairs (area vs perimeter, × vs ÷); 30% of items from earlier concepts |
| 6 | Explanatory feedback, levelling | [Outhwaite 2023](https://bera-journals.onlinelibrary.wiley.com/doi/10.1111/bjet.13339) (77 apps): levelling + explanatory + praise; [Math Garden](https://www.sciencedirect.com/science/article/abs/pii/S0360131511000418): 75% success target | Wrong answer: one narrated reason tied to its bug; difficulty steps to ~75–85% first-try; praise strategy ("you made a ten") |
| 7 | Hints that can't be gamed | [Aleven](https://link.springer.com/article/10.1007/s40593-015-0089-1): 68% of hint levels viewed under 1 s; help abuse ↔ less learning | Hint n+1 unlocks after narration n plus one attempt; hint 3 = worked step; item re-served with new numbers, max 1 star |
| 8 | Low anxiety | Anxiety–achievement small/moderate, reciprocal ([223 studies](https://www.researchgate.net/publication/346551018_A_meta-analysis_of_the_relation_between_math_anxiety_and_math_achievement)); "timed tests cause anxiety" ([Boaler](https://www.youcubed.org/evidence/fluency-without-fear/)) is [contested](https://hechingerreport.org/proof-points-do-math-drills-help-children-learn/) | No visible timers, lives, leaderboards by default; hidden latency only schedules review; opt-in "beat your own time" for tables at ≥ 90% accuracy (parent toggle) |
| 9 | Game = the skill | [Habgood & Ainsworth 2011](https://tecfa.unige.ch/tecfa/teaching/BSEP/articles/Habgood_Ainsworth_2011.pdf), ages 7–8: integrated mechanic → more learning (later replications mixed) | Boss mechanic is the maths act (build array, pay coins), never a quiz gate or unrelated loot |

Mastery ≥ 80% of max stars = mean ≥ 2.4/item, i.e. ≥ 40% of items at 3 stars if the rest are 2. Stars: 3 = first try, no hint; 2 = one error or hint 1; 1 = hint 2–3 or 2 errors; re-served bottom-out items cap at 1.

## 3. Exercise types

Hint ladder (all types): H1 re-narrate + highlight (no new information); H2 show the representation or misconception visual; H3 worked first step, child finishes. Check exact unless noted; retries re-seeded.

| Type | Interaction · machine check | H1 / H2 / H3 specifics |
|---|---|---|
| MC | 2–4 cards (picture or numeral); id match. ≤ 20% of scored items, never for fluency (guessable) | highlight key words / picture / cross out wrong options |
| NE | on-screen pad (digits, ⌫, ✓); integer compare; locale decimal mark | highlight / blocks, line or array / leading digit pre-filled |
| NL | tap or drag marker; labelled ticks exact, estimates within ±½ interval, score by % error | midpoint benchmark / more ticks / marker near target |
| CMP | drag <, =, > tile; evaluate both sides | highlight / aligned bars or blocks / highest place first |
| ARR | drag row/column handles or fill groups; rows × cols = target, commutative accepted unless "rows" fixed | "rows go across" / row total shown / rows auto-filled |
| PV | drag 100/10/1 blocks to columns; auto-exchange animation at 10; check column state | column labels / numeral beside blocks / hundreds pre-placed |
| FR | tap parts to shade, or split bar into n equal parts; shaded/total compared; unequal parts rejected | outline whole / "1 of 4 equal parts" / first part shaded |
| CLK | drag hands (hour hand follows minute), ±2 min tolerance; or read → pad | name the hand / label 5-min marks / hour hand set |
| COIN | drag coins/notes to tray; sum = amount, any combination (or "fewest"); change = pick returned coins; EUR/GBP/USD skins | show target / running total / largest coin that fits |
| BAR | tile model (part-whole, comparison, equal groups), drop knowns, mark "?"; structure vs template, then NE | highlight sentence / model outline / knowns filled |
| MISS | blank in any position (□ + 7 = 15; 20 = □ × 4); numeric | read as question / fact-family picture / inverse shown |
| TF | true/false tile on equation or worked solution ("spot the mistake"); evaluate | narrate / balance scale / left side computed |
| SORT | drag cards into order or categories (odd/even, acute/obtuse); exact order, inversions drive feedback | "biggest first" / line or blocks / first two placed |

Six boss mechanics, built once and parametrised per lesson:
- Order-queue (customer animals ask, child serves): 2.5, 5.4, 6.6, 7.1, 7.4.
- Build-to-spec (array garden, fence, vending code, bridge): 1.1, 2.3, 4.2, 8.4–8.5.
- Target-hit (frog, archery, stepping stones): 1.3, 1.5, 6.3, 8.2.
- Sort-conveyor: 1.2, 6.4, 8.1, 8.3.
- Memory pairs: 2.1, 4.4, 6.5.
- Track race vs bot: 4.5–4.6 and the games below.

Two-player games vs bot (solved games, so bots are a few lines; levels = mistake rate 40/20/0%; replay flags your first losing move):

| Game | Rules | Skill | Bot / hint |
|---|---|---|---|
| Race to 20 | alternate adding 1–3; reach 20 wins; winning totals = multiples of 4. Variants: to 30 with 1–4; to 100 with 1–10 (leave 89, 78, …, 1) | multiples, remainders, ÷ | move = (target − total) mod (max+1), random if 0. Hint: "leave a multiple of 4" |
| Two-pile Nim | take any number from one pile; last stone wins; equal piles lose for mover | patterns | keep piles equal. E: 3 piles (XOR) |
| Product Game | two clips on factors 1–9; shade the product on a 6×6 board; connect 4 | tables, factors | greedy block/extend |
| Place-value duel | roll digit 0–9, place into one of 3 slots, higher number wins | place value | high digits to high places |

## 5. Content generation

Item = template(params) → {prompt, answer, distractors tagged by bug id, difficulty, rep}. An independent solver recomputes every answer; validator checks unique answer and distinct distractors; stored seed lets review replay the item. Each bug id has one authored explanation sentence + one H2 visual, reused everywhere.

| Topic | Generated (difficulty levers) | Misconception → distractor |
|---|---|---|
| Place value | 3–4 digits; zero in tens/ones raises level | 205 → 2005 (append); 352 → 325; "3 hundreds" → 3 ([list](https://thirdspacelearning.com/blog/common-errors-misconceptions-primary-maths-ks1-ks2/)) |
| Compare/order | shared leading digits; different lengths | longer = bigger (fails on decimals, fractions) |
| Number line | tick step 1/2/5/10/100; target off-tick | counts ticks not intervals ([study](https://files.eric.ed.gov/fulltext/EJ1099630.pdf)) |
| Mental +/− | bridging (ones sum 11–18); near double (a ≤ 50); ±9/±99 | 8+7 = 14; off by 10; wrong operation |
| Column +/− | rejection-sample by #carries, #exchanges, zero in tens | buggy-algorithm library: smaller-from-larger (304−168 = 264), no carry, no decrement after exchange ([NCETM](https://www.ncetm.org.uk/classroom-resources/cp-year-3-unit-7-column-subtraction/)) |
| Tables | (a,b) weighted by Leitner box + error history | a×(b±1); a+b; digit swap 42/24; × vs ÷ |
| Division | n = q×d (+r), q, d from known tables | d÷q reversed; remainder as extra group; "÷ commutes" |
| Fractions | denominators 2,3,4,5,6,8,10 (E: 12, 100); equal parts only | bigger denominator = bigger fraction; unequal pieces; ticks not gaps; a/b + c/b = (a+c)/2b |
| Time | minutes step 5 → 1; hour hand consistent; durations within hour → across noon | swapped hands; hand on 4 = 4 min; 2:50 read 3:50; 2:45→3:10 = 65 ([errors](https://bioone.org/journalArticle/Download?urlId=10.3101%2FKYAC-84-01-03)) |
| Money | amount bands; locale skin | 2.5 = 2.05; count coins not values |
| Measures | unit pairs; scale step 2/5/10 | skipped scale lines; ×10 vs ×100 |
| Geometry | shapes from property table, random rotation; rectangles for P/A | rotated square ≠ square; right angle only upright "L"; P = a+b or a×b; A = border squares ([P/A](https://cognitivecardiomath.com/cognitive-cardio-blog/confuse-area-and-perimeter/)) |
| Data | datasets; icon = 1/2/5/10 | ignores key; reads between bars |

Equals sign: include 7 + 5 = 6 + □ in every operation world (children read "=" as "answer next").

Authored: stories, demos, boss levels, word-problem frames (schema tag: part-whole, change, comparison, equal groups, multiplicative comparison, two-step; ≥ 3 number sets; keyword traps such as "altogether" in a comparison), "spot the mistake" solutions, shape art, it/en number narration, reason sentences per bug.

## 6. Pitfalls and evidence from comparable apps

| App | Evidence found | Lesson for us |
|---|---|---|
| [DragonBox 12+](https://www.tandfonline.com/doi/full/10.1080/19345747.2023.2269918) | RCT, 1 850 middle-schoolers: effect 0.27 vs active control. [Long & Aleven](https://dl.acm.org/doi/10.1145/3057889): less gain than a tutor | engaging ≠ transferring; add explicit symbol-level bridge (A stage) |
| Prodigy | vendor and [correlational](https://jscholarship.library.jhu.edu/bitstreams/c38fbad0-2746-4c00-8654-5d0854d2a99c/download) studies; [critics](https://fairplayforkids.org/pf/prodigy/): off-maths time, membership pressure | no reward economy detached from maths |
| Khan Academy / Kids | [~350k students](https://blog.khanacademy.org/khan-academy-efficacy-results-november-2024/): ~9% reached 30 min/week; no Kids maths RCT found | dosage matters: parent view of minutes/week |
| Number Race, Calcularis | [open trial](https://pmc.ncbi.nlm.nih.gov/articles/PMC1523349/): comparison and subitising up, limited transfer | number-sense games supplement lessons |
| Times Tables Rock Stars | [no formal studies](https://explore.bps.org.uk/content/bpsdeb/1/189/14); parents report timer stress; timer hideable | default untimed; timed mode opt-in |
| Fraction games | Motion Math +15% in 5 days ([study](https://www.researchgate.net/publication/258137306_Results_From_a_Controlled_Study_of_the_iPad_Fractions_Game_Motion_Math)); RCTs: [trained task only](https://pubmed.ncbi.nlm.nih.gov/35078086/); [below control](https://onlinelibrary.wiley.com/doi/abs/10.1111/jcal.12726) | keep Story/Demo/direct instruction around games |
| App stores | [Hirsh-Pasek](https://journals.sagepub.com/doi/abs/10.1177/1529100615569721): most apps tap-and-react; free apps distract | every item "minds-on", no decorative effects |

Game-based maths meta-analyses range from d≈0.13 ([24 studies](https://www.researchgate.net/publication/330759904_Effects_of_game-based_learning_on_students'_mathematics_achievement_A_meta-analysis), per excerpt) to g>1: distrust headlines.

Other pitfalls:
- Keyword strategy ("altogether" → add) fails on comparisons ([note](https://thirdspacelearning.com/blog/teach-bar-model-method-arithmetic-maths-word-problems-ks1-ks2/)); teach structure via BAR.
- "1.000" = one thousand in Italy: no separator at 4 digits, thin space from 5; decimal mark per locale.
- Locale pack: ÷ shown as ":" in Italy; exchange / regroup / prestito; 12/24 h.
- Currency: EUR and GBP share 1, 2, 5, 10, 20, 50, 100, 200 units; USD differs (25¢, no 2¢/20¢). One skin per item.
- The 80% gate must not be reachable with one representation: keep A-only items.
